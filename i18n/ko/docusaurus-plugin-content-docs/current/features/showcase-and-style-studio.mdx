# 쇼케이스와 스타일 스튜디오

개발 모드에서는 별도 쇼케이스 메뉴가 모든 공유 컴포넌트를 모은 카탈로그를 엽니다. 로컬 개발 중에는 스타일 스튜디오로 카탈로그의 디자인 토큰을 편집하고 스타일시트에 다시 저장할 수 있습니다.

## 컴포넌트 쇼케이스

- 개발 모드에서만 사이드바의 별도 메뉴로 `/show-case`를 열며, 게스트와 로그인 사용자 모두 사용할 수 있습니다. 운영 모드에서는 쇼케이스 URL이 `/home`으로 이동합니다. 랜딩 페이지는 `/welcome`에 있습니다.
- 모든 공유 UI 컴포넌트에 동작하는 예제가 있으며, 카테고리별로 묶여 있고 검색할 수 있습니다.
- 미리보기는 계정 API를 호출하거나 OAuth를 시작하지 않습니다.
- 새 공개 UI export에 쇼케이스 예제가 없으면 `make ui-composition-check`가 실패합니다.
- `MainPageTemplate`, `AccountDeletionDialog`, 간결한 `DropdownMenu` 작업 메뉴, `SegmentedControl` 같은 기능 조합도 실제 API를 호출하지 않는 검색 가능한 예제를 가집니다.

## 스타일 스튜디오

백엔드를 실행한 뒤 편집기를 시작합니다.

```bash
make backend-dev
make frontend-style-studio   # 편집기가 켜진 Vite를 127.0.0.1에서 실행
```

`http://127.0.0.1:5173/show-case`를 엽니다. 사이드 패널에서 다음을 미리 볼 수 있습니다.

- 배경, 패널, 입력, 텍스트, 버튼, hover 상태의 라이트·다크 색상
- 모서리 반경, 간격, 글꼴, 크기, 굵기, 줄 높이

**적용**은 토큰을 검증하고 이전 CSS를 `.style-studio-backups/`에 백업한 뒤 `src/frontend/src/styles/app.css`에 기록합니다. 이 변경은 일반적인 B4React 작업 트리 변경이므로 B4React 브랜치와 PR로 커밋한 뒤 고정 커밋을 갱신합니다.

:::note

편집기는 루프백 전용 로컬 모드에서만 존재합니다. `make frontend-dev`, 프로덕션 빌드, 데스크톱 빌드에는 포함되지 않습니다.

:::

별도 B4React 체크아웃을 편집하려면 `FRONTEND_DIR=/absolute/path/to/B4React`를 지정합니다.
