# 설정과 프로필

B4React는 크기 조절 가능한 사이드바, 설정 작업 공간, 프로필 편집, 라이트·다크 테마, 키보드 단축키, 토스트 피드백을 갖춘 완성된 앱 셸을 제공합니다.

## 앱 셸

- 고정 사이드바: 접힘 48px, 펼침 224px, 200–360px 사이로 크기 조절. 너비는 저장됩니다.
- 프로필과 연결 상태는 사이드바 하단에 있습니다.
- 모바일에서는 사이드바가 닫을 수 있는 배경과 함께 콘텐츠 위에 표시됩니다.

## 설정 섹션

| 섹션   | 대상          | 내용                                    |
| ------ | ------------- | --------------------------------------- |
| 일반   | 모두          | 언어(영어, 한국어)                      |
| 모양   | 모두          | 미리보기가 있는 시스템·라이트·다크 테마 |
| 프로필 | 로그인 사용자 | 이름, 프로필 사진, 연결된 로그인 방식   |
| 개발자 | 로그인 사용자 | [API 키](/docs/features/api-keys)       |

섹션은 URL(`/settings?section=...`)에 포함됩니다. 게스트가 계정 전용 섹션을 열면 일반으로 이동합니다.

## 키보드 단축키

| 단축키                        | 동작               |
| ----------------------------- | ------------------ |
| <kbd>Mod</kbd> + <kbd>B</kbd> | 사이드바 열기·닫기 |
| <kbd>Mod</kbd> + <kbd>,</kbd> | 설정 열기          |

<kbd>Mod</kbd>는 macOS에서 Command, Windows와 Linux에서 Control입니다.

## 토스트

명시적인 작업이 끝나면 화면 상단에 짧은 캡슐 토스트로 한 번 알립니다. 로그인·로그아웃, 가입, 인증 메일 재발송, 비밀번호 재설정, 프로필 변경, API 키 작업, 비밀 값 복사가 해당됩니다. 입력 검증 오류는 입력 필드 옆에 표시하고, 토스트에는 비밀번호, 비밀 값, 토큰을 넣지 않습니다.

## 다국어

모든 UI 문구는 react-i18next로 영어와 한국어를 제공합니다. 인증 메일은 사용자 언어를 따릅니다.
