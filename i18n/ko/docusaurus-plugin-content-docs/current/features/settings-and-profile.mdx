# 홈, 설정과 프로필

B4React는 기본 홈 화면, 크기 조절 가능한 사이드바, 설정 작업 공간, 계정·프로필 편집, 라이트·다크 테마, 사용자 지정 키보드 단축키, 토스트 피드백을 갖춘 완성된 앱 셸을 제공합니다.

## 홈

`/home`은 두 [런타임 모드](/docs/environment/runtime-modes) 모두의 기본 페이지입니다. `/`, `/dashboard`, 로그인 완료, 인증 대화상자 닫기, 페이지 복구는 모두 홈으로 이동합니다.

| 사용자         | 표시 내용                                                |
| -------------- | -------------------------------------------------------- |
| 게스트         | 일반 콘텐츠와 로그인 진입점, 개인 데이터는 불러오지 않음 |
| 로그인 사용자  | 인사말과 계정, 결제(활성화 시), 환경설정 바로가기        |
| 매니저, 관리자 | 사용자 목록 바로가기 추가                                |

홈은 제품 확장을 위한 표현용 레이아웃인 `src/components/layout`의 `MainPageTemplate`으로 만듭니다.

| Prop                           | 용도                                                   |
| ------------------------------ | ------------------------------------------------------ |
| `title`, `description`, `icon` | 제목 영역                                              |
| `actions`                      | 기존 컴포넌트로 구성한 헤더 컨트롤                     |
| `menuLabel`, `menuItems`       | ID, 라우트, 제목, 아이콘을 가진 접근성 있는 내비게이션 |
| `menuLayout`                   | `list`(기본) 또는 반응형 `grid`                        |
| `children`                     | 추가 섹션, 목록, 카드, 로딩·빈 상태                    |

템플릿은 인증, API, 라우팅 상태, 저장소를 소유하지 않습니다. 이를 사용하는 페이지가 권한에 따라 항목을 거르고 훅으로 자체 데이터를 불러옵니다.

## 앱 셸

- 고정 사이드바: 접으면 48px, 펼치면 224px이며 200–360px 사이로 크기를 조절할 수 있습니다. 너비는 기억됩니다.
- 사이드바 하단에 프로필 컨트롤과 연결 상태가 있습니다. 개발 모드에서는 프로필 컨트롤 바로 위에 GitHub와 사용 가이드 링크가 있습니다.
- 결제가 켜져 있으면 프로필에 구독 등급이 표시되고, 프로필 메뉴에서 `/plans`를 엽니다.
- 모바일에서는 사이드바가 콘텐츠 위에 겹쳐지며 배경을 눌러 닫을 수 있습니다.
- 서버에 연결할 수 없을 때도 복구 패널이 같은 사이드바 레이아웃 안에 표시됩니다.

## 설정 섹션

| 섹션   | 대상                          | 내용                                                                        |
| ------ | ----------------------------- | --------------------------------------------------------------------------- |
| 일반   | 모두                          | 언어(영어, 한국어)                                                          |
| 모양   | 모두                          | 미리보기가 있는 시스템·라이트·다크 테마                                     |
| 키보드 | 모두(편집은 로그인 사용자)    | 단축키 지정                                                                 |
| 계정   | 로그인 사용자                 | 이름, 프로필 사진, 이메일, 연결된 로그인 방식, 계정 삭제                    |
| 결제   | 로그인 사용자, 결제 활성화 시 | 요금제, 거래 내역, 청구 정보, 결제수단. [결제](/docs/features/billing) 참고 |
| 개발자 | 로그인 사용자                 | [API 키](/docs/features/api-keys)                                           |

섹션은 URL의 일부입니다(`/settings?section=...`). 이전의 `section=profile`은 계정 섹션을 엽니다. 게스트가 계정 전용 섹션을 열면 일반으로 이동하고, 결제가 꺼져 있으면 결제 섹션도 일반으로 이동합니다.

## 계정과 프로필

- **이름** 변경은 토스트로 확인하며, 오류는 입력란 옆에 표시합니다.
- **프로필 사진**은 바이너리 이미지로 업로드하고 API를 통해 비공개로 제공합니다. [오브젝트 스토리지](/docs/features/object-storage#profile-photos)를 참고하세요.
- **계정 삭제**는 하단의 별도 섹션에 있으며, 등록된 이메일과 그 주소로 보낸 6자리 코드를 입력해야 합니다. [인증](/docs/features/authentication#account-deletion)을 참고하세요.

## 키보드 단축키

| 동작          | 기본값                        |
| ------------- | ----------------------------- |
| 사이드바 토글 | <kbd>Mod</kbd> + <kbd>B</kbd> |
| 설정 열기     | <kbd>Mod</kbd> + <kbd>,</kbd> |

<kbd>Mod</kbd>는 macOS에서는 Command, Windows와 Linux에서는 Control입니다.

단축키는 계정에 저장되므로(`GET/PATCH /auth/me`의 `keyboard_shortcuts`) 브라우저와 기기를 바꿔도 유지됩니다. 게스트는 기본값을 읽기 전용으로 봅니다. 충돌하는 단축키는 거부되고, 저장이 확인된 경우에만 활성 단축키가 바뀌며, **초기화**는 기본값으로 되돌립니다. 이미 열려 있는 다른 클라이언트에는 새로고침이나 로그인 후 반영됩니다.

## 토스트와 피드백

명시적인 작업이 끝나면 화면 상단에 짧은 캡슐 토스트로 한 번 알립니다. 로그인·로그아웃, 가입, 인증 메일 재발송, 비밀번호 재설정, 프로필 변경, API 키 작업, 결제 확인, 비밀 값 복사가 해당됩니다. 입력 검증 오류는 입력란 옆에, 지속되는 안내는 `InlineMessage`로 표시하며, 토스트에는 비밀번호, 비밀 값, 토큰을 넣지 않습니다.

## 다국어

모든 UI 텍스트는 react-i18next로 영어와 한국어로 번역됩니다. 이메일은 사용자의 언어를 따릅니다.
