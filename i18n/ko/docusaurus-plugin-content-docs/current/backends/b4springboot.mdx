# B4SpringBoot <Badge tone="warn">예정</Badge>

B4SpringBoot는 B4Agent의 두 번째 백엔드 블루프린트가 될 예정이며, 아직 공개되지 않았습니다.

## 그대로 유지되는 것

- **프론트엔드.** B4FastAPI와 똑같이 B4React를 `src/frontend`에 Git 서브모듈로 고정합니다.
- **API 계약.** 인증, 쿠키, 오류 코드, 준비 상태, Server-Sent Events 동작을 포함해 같은 `contracts/openapi.json`을 구현해야 합니다. 스키마가 같다는 것만으로 이 동작 테스트를 대신할 수 없습니다.
- **하네스.** `AGENTS.md` 읽기 순서, worklog, Git 거버넌스, 변경 범위 기반 검증이 같은 방식으로 적용됩니다.

## 달라지는 것

- 백엔드 스택, 빌드 도구, 테스트 실행기
- B4React `dist`를 제공하기 위한 자체 패키징 어댑터
- 개발 중에는 `VITE_API_BASE_URL=http://localhost:8080`으로 B4React를 연결합니다.

저장소가 공개되면 이 매뉴얼의 **백엔드** 아래에 B4SpringBoot 전용 페이지를 추가합니다. 그 전까지 모든 기능과 옵션 페이지는 B4FastAPI 기준입니다.
