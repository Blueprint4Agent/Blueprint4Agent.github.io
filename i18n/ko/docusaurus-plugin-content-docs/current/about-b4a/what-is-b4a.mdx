# What is B4A?

Blueprint4Agent는 실무형 웹 서버 블루프린트와 에이전트 기반 자동화 기반을 위한 조직 수준 문서 허브입니다.
이 문서는 Blueprint4Agent 저장소 전반에서 공유하는 컨텍스트, 프로젝트 구성, 운영 기준을 정의합니다.

이 문서 사이트는 조직 공통 가이드와 저장소별 구현 세부사항을 분리합니다.
팀은 안정적인 규칙은 이곳에서 확인하고, 설정과 구현 지침은 각 프로젝트 저장소에서 확인할 수 있습니다.

## Project Overview

Blueprint4Agent는 프로덕션 프로젝트를 만드는 팀을 위해 실무형 웹 서버 블루프린트와 에이전트 기반 자동화 기반을 제공합니다.
반복 가능한 설정, 명확한 저장소 경계, 구현 중에도 유용한 문서를 중점에 둡니다.

## Project Purpose

목적은 팀이 코드, 문서, 자동화 워크플로에 대해 일관된 기준으로 저장소를 시작하고 운영하도록 돕는 것입니다.
Blueprint4Agent는 추상적인 프로세스 문서보다 구현 우선의 실용적인 가이드를 선호합니다.

## Project Composition

- `B4F` - FastAPI 블루프린트 저장소
- `B4B` - 에이전트 기반 자동화 및 리뷰 플로우 저장소 (예정)
- `Blueprint4Agent.github.io` - Docusaurus 기반 문서 웹사이트

## Documentation Model

이 사이트는 프로젝트 개요, 목적, 구성, 문서화 규칙, 공통 운영 기준 같은 조직 수준 문서를 담당합니다.
저장소별 기술 세부사항은 해당 구현이 존재하는 저장소에 작성해야 합니다.

## Next Steps

이 페이지를 Blueprint4Agent 컨텍스트의 진입점으로 사용합니다.
설정 또는 구현 세부사항이 필요하면 관련 저장소 문서로 이동합니다.
