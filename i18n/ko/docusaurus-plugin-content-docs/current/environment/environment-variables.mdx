# 환경변수

B4FastAPI는 `.env` 파일 세 개를 읽습니다. 각 파일에는 커밋된 `.env.example`이 있으며, 키·기본값·주석·순서의 기준이 됩니다.

| 파일                | 사용처                                                       | 생성 방법   |
| ------------------- | ------------------------------------------------------------ | ----------- |
| `src/backend/.env`  | `make backend-dev`, 테스트, `make user-role`, 로컬 Celery    | `make init` |
| `docker/.env`       | Docker Compose: app, Celery, PostgreSQL, Redis, 옵저버빌리티 | `make init` |
| `src/frontend/.env` | Vite 개발 서버와 프론트엔드 빌드                             | `make init` |

## 파일 동기화

| 명령                                             | 동작                                                                                                        |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| `make env-sync`                                  | 기존 값을 유지하며 예제 기준으로 백엔드·프론트엔드 `.env`를 다시 구성합니다. 새 키는 기본값으로 추가합니다. |
| `make env-check`                                 | 누락·중복·잘못된 키와 오래된 구성을 발견하면 실패합니다.                                                    |
| `make docker-env-sync` / `make docker-env-check` | `docker/.env`에 대해 같은 작업을 합니다.                                                                    |
| `make env-contract-check`                        | 실제 `.env` 없이 백엔드와 Docker 예제가 같은 공유 키를 선언했는지 확인합니다.                               |

- 파일을 바꾸기 전에 `.env-backups/`에 시각이 붙은 백업을 남깁니다(Git·Docker 제외, 본인만 읽기 가능).
- 값은 출력하지 않습니다. 내 `.env`에만 있는 키는 파일 끝의 별도 구역에 유지됩니다.
- 예제는 구역 구분선으로 묶여 있고, 각 키 바로 위의 `# Values:` 주석이 허용 값이나 형식을 알려줍니다. 동기화는 이 배치와 주석을 그대로 복사합니다.
- 모든 배포가 먼저 실행하는 `make docker-check`는 안전하지 않은 운영 값을 거부합니다. [서버 배포](/docs/environment/deployment#check-and-deploy)를 참고하세요.

:::tip[설정 추가]

공유 백엔드 설정은 `src/backend/.env.example`과 `docker/.env.example` 양쪽에 추가합니다. 한쪽에 빠지면 `make check`와 로컬 검증에서도 실행되는 `make env-contract-check`가 실패합니다.

:::

## 백엔드 변수

아래 기본값은 `src/backend/.env.example`(로컬 개발) 기준입니다. 값이 다른 [Docker 기본값](#docker-기본값)은 뒤에 정리합니다.

### 서버

| 변수                  | 기본값                                                          | 설명                                                                                                              |
| --------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `APP_NAME`            | `Blueprint4FastAPI API`                                         | OpenAPI에 표시되는 API 이름                                                                                       |
| `APP_MODE`            | `development`                                                   | `development` 또는 `production`. [런타임 모드](/docs/environment/runtime-modes) 참고                              |
| `APP_ENV`             | `local`                                                         | 텔레메트리 라벨(Docker에서는 `docker`), 모드를 정하지 않음                                                        |
| `LOG_LEVEL`           | `INFO`                                                          | Python 로그 레벨                                                                                                  |
| `STARTUP_DISPLAY`     | `auto`                                                          | `auto`, `plain`, `off`. [시작 화면과 콘솔 로그](/docs/environment/startup-and-logs) 참고                          |
| `APP_LAYOUT`          | `sidebar`                                                       | `sidebar`, `topnav`, `focused`. [레이아웃](/docs/features/settings-and-profile#layouts) 참고                      |
| `DEMO_ENABLED`        | `false`                                                         | 공개 읽기 전용 [관리자 데모](/docs/features/admin-and-roles#admin-demo)                                           |
| `APP_PORT`            | `8000`                                                          | `make backend-dev` 포트                                                                                           |
| `APP_BASE_URL`        | `http://localhost:5173`                                         | 이메일 링크와 OAuth 리다이렉트에 쓰는 공개 프론트엔드 URL, `APP_BASE_PATH` 포함                                   |
| `APP_BASE_PATH`       | _(비어 있음)_                                                   | `/my-app` 같은 공개 URL 접두사, 비어 있거나 `/`이면 루트. [basePath](/docs/environment/deployment#base-path) 참고 |
| `FORWARDED_ALLOW_IPS` | `127.0.0.1`                                                     | Uvicorn이 forwarded 헤더를 신뢰할 프록시 IP 또는 CIDR                                                             |
| `SWAGGER_ENABLED`     | `true`                                                          | `/docs`에서 Swagger UI 제공                                                                                       |
| `METRICS_ENABLED`     | `true`                                                          | `/metrics`에서 Prometheus 메트릭 제공                                                                             |
| `CORS_ORIGINS`        | `http://localhost:5173,http://127.0.0.1:5173,tauri://localhost` | 쉼표로 구분한 허용 origin                                                                                         |

## Docker 기본값

`docker/.env.example`은 같은 백엔드 키를 선언하되 컨테이너용 기본값이 다릅니다.

| 변수                                | Docker 기본값                                            |
| ----------------------------------- | -------------------------------------------------------- |
| `APP_MODE`                          | `production`                                             |
| `APP_ENV`                           | `docker`                                                 |
| `APP_BASE_URL`                      | `http://localhost:8000`                                  |
| `CORS_ORIGINS`                      | `http://localhost:8000` 추가                             |
| `OTEL_EXPORTER_OTLP_ENDPOINT`       | `http://otel-collector:4317`                             |
| `DB_DRIVER` / `DB_NAME` / `DB_HOST` | `postgresql+asyncpg` / `template` / `postgres`           |
| `REDIS_IN_MEMORY` / `REDIS_HOST`    | `false` / `redis`                                        |
| `OBJECT_STORAGE_LOCAL_ROOT`         | `/var/lib/b4fastapi/objects`(`object_storage_data` 볼륨) |

Docker 전용 키도 있습니다.

| 변수                                          | 기본값                      | 설명                                                                           |
| --------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------ |
| `APP_IMAGE`                                   | `blueprint4fastapi:local`   | 앱 이미지 태그                                                                 |
| `COMPOSE_FILE`                                | `docker-compose.yml`        | Compose 오버레이, `docker-compose.yml:docker-compose.https.yml`이면 Caddy 추가 |
| `PUBLIC_DOMAIN`                               | _(비어 있음)_               | HTTPS 오버레이용 호스트 이름                                                   |
| `COMPOSE_PROJECT_NAME`                        | `docker`                    | Compose 프로젝트. 컨테이너와 볼륨을 결정                                       |
| `APP_HOST_PORT`                               | `8000`                      | `127.0.0.1`에 게시                                                             |
| `POSTGRES_HOST_PORT`                          | `5432`                      | `127.0.0.1`에만 공개                                                           |
| `REDIS_HOST_PORT`                             | `6379`                      | `127.0.0.1`에만 공개                                                           |
| `GRAFANA_HOST_PORT`                           | `3000`                      | `127.0.0.1`에만 공개                                                           |
| `PROMETHEUS_HOST_PORT`                        | `9090`                      | `127.0.0.1`에만 공개                                                           |
| `OTEL_GRPC_HOST_PORT` / `OTEL_HTTP_HOST_PORT` | `4317` / `4318`             | `127.0.0.1`에만 공개                                                           |
| `PROMETHEUS_BACKEND_TARGET`                   | `host.docker.internal:8000` | Prometheus가 수집할 백엔드(Docker 앱은 `app:8000`)                             |
| `GRAFANA_ADMIN_USER`                          | `admin`                     | 새 볼륨의 Grafana 관리자                                                       |
| `GRAFANA_ADMIN_PASSWORD`                      | _(비어 있음)_               | Grafana 시작에 필수. `admin`, `CHANGE_ME*`는 거부                              |

| `INDEXNOW_ENABLED` | `false` | `docker-deploy` 성공 후 변경된 공개 URL 제출 |

Docker 파일은 [공개 빌드 값](/docs/environment/deployment#public-build-values)인 `VITE_PUBLIC_SITE_URL`, `VITE_SITE_DESCRIPTION`, `VITE_PUBLIC_DISCOVERY`, `VITE_INDEXNOW_KEY`, `VITE_BUY_ME_A_COFFEE_ENABLED`, `VITE_BUY_ME_A_COFFEE_URL`도 프론트엔드 빌드에 전달합니다. 바꾸면 다시 빌드해야 합니다.

`$`가 들어간 값은 Compose 보간을 막기 위해 작은따옴표로 감쌉니다.

| `VITE_API_BASE_URL`            | _(비어 있음)_ | API origin. 비어 있으면 개발 중에는 `http://localhost:8000`, 다른 웹 빌드는 페이지 자신의 origin을 사용. 데스크톱 빌드, 별도 호스팅, 다른 백엔드에서 지정 |
| `VITE_BASE_PATH`               | _(비어 있음)_ | 별도 Vite 개발 서버의 basePath. 패키징된 빌드는 런타임 `APP_BASE_PATH`를 읽음                                                                             |
| `VITE_PUBLIC_SITE_URL`         | _(비어 있음)_ | 공유 메타데이터와 검색 공개 페이지의 공개 origin                                                                                                          |
| `VITE_SITE_DESCRIPTION`        | _(비어 있음)_ | 정적 HTML의 설명                                                                                                                                          |
| `VITE_PUBLIC_DISCOVERY`        | `false`       | 정적 `/about/`, `/about/ko/` 소개 페이지 빌드                                                                                                             |
| `VITE_INDEXNOW_KEY`            | _(비어 있음)_ | 공개 IndexNow 소유 키                                                                                                                                     |
| `VITE_BUY_ME_A_COFFEE_ENABLED` | `false`       | 셸에 후원 링크 표시, 개발 모드에서만                                                                                                                      |
| `VITE_BUY_ME_A_COFFEE_URL`     | _(비어 있음)_ | 쿼리·fragment·포트가 없는 HTTPS `buymeacoffee.com` 크리에이터 URL                                                                                         |

모든 `VITE_*` 값은 공개 빌드 시점 값입니다. 비밀값을 넣지 않습니다.
